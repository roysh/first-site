How I write and publish articles on this site

Dr. Shantanu Roy

This site has a built-in Writing section. There is no CMS and no database — each article is a simple HTML file, and publishing a new one takes about two minutes.

1. Copy the template

Duplicate posts/post-template.html and rename it, e.g. posts/why-rag-projects-fail.html. Use lowercase words joined by dashes.

2. Edit the content

Open the file and change three things:

  • The <title> tag (browser tab)
  • The <h1> (article headline) and the date line under it
  • The article body — paragraphs, headings, lists, code blocks, quotes

3. Add it to the list

In writing.html, copy an existing row inside the post-list div and update the link and title. Newest article goes on top.

4. Push to GitHub

git add .
git commit -m "New article: why RAG projects fail"
git push

Cloudflare Pages rebuilds and deploys automatically within a minute. That's it — the article is live.

Why this setup?

Static publishing is the same philosophy I bring to client work: no moving parts, no monthly SaaS bill, no maintenance, version-controlled forever. A blog that still works in ten years is a better asset than one that depends on a platform.

Publish on your own domain. Platforms rent you an audience; a website owns one.
